1Быстрый старт

«Натяжка» (TapTension) проверяет натяжение гибкого подвеса — шнура, соединяющего стороны подрамника, — по звуку удара, как гитарный тюнер. Звук сравнивается с эталоном, записанным для этого размера подрамника, по трём признакам: частоте тона, времени затухания и чистоте тона.

  1. Установите приложение из RuStore или откройте ссылку на него в Chrome на телефоне и добавьте на главный экран кнопкой «📲 Установить» вверху экрана.
  2. На вкладке «Холсты» выберите размер подрамника.
  3. Запишите эталон на правильно натянутом изделии — раздел 2.
  4. Проверяйте каждое изделие перед упаковкой — раздел 3.

Режимов два, переключатель — вверху экрана и в ⚙ Настройках:

  • «Лайт» — проверить натяжение: размер холста, эталон, удар, вердикт. Разделы 2–5.
  • «Про» — проверка по регламенту: номер заказа, исполнитель, контрольный ключ, отметка о провисании, повторная проверка после корректировки, реестр, выгрузки и отчёт за период. Раздел 6.
Все данные хранятся только на телефоне. Интернет нужен лишь для первой загрузки — дальше приложение работает и без сети.

2Эталон для размера холста

Каждый размер хранит свой эталон — запись удара по правильно натянутому шнуру. С ним сравниваются все проверки этого размера.

Добавление размера

На вкладке «Холсты» выберите готовый слот из сетки основных размеров или добавьте свой через «+ Свой размер».

Запись эталона

  1. Откройте нужный размер на вкладке «Тюнер».
  2. Нажмите «🎙 Записать образец» — приложение слушает 3 секунды.
  3. Сразу ударьте шестигранным ключом 4–5 мм по середине шнура, перпендикулярно шнуру, рядом с микрофоном. Не глушите шнур рукой — дайте звуку затихнуть.
  4. Приложение покажет частоту, время затухания и чистоту тона. Прослушайте запись, при необходимости запишите заново и нажмите «Сохранить как эталон».
Каждый раз — тот же ключ, та же точка удара и примерно то же расстояние до телефона (10–20 см). От этого зависит, насколько корректно сравниваются показания.

Частоту эталона можно ввести и вручную, в герцах. Затухание и чистота тона при этом не проверяются, пока не записан образец.

Эталоны, записанные в версии 2.2, приложение пересчитает само при первом открытии размера: затухание и чистота тона берутся из сохранённой записи.

3Повседневная проверка

  1. Выберите размер холста в списке на вкладке «Тюнер».
  2. Нажмите «🎙 Слушать и сравнивать».
  3. Ударьте тем же ключом по центру шнура, перпендикулярно шнуру.
  4. Подождите около секунды, пока звук затихнет: приложение измерит затухание и покажет вердикт.

Точность измерения

  • Чувствительность (Тихо / Обычно / Шумно) — под уровень шума в помещении.
  • «Среднее по 3» — вердикт по трём последним ударам вместо одного. Только в режиме «Лайт»: в «Про» каждая проверка — один удар.
  • Вибрация: одна длинная — норма, двойная — вне допуска по частоте, тройная — брак.

4Как выносится вердикт

ПризнакЧто измеряется
ЧастотаОсновной тон удара. Допуск по умолчанию ±3%. Частота шнура растёт как корень из натяжения, поэтому ±3% по частоте — это примерно ±6% по натяжению.
ЗатуханиеВремя, за которое основной тон стихает на 20 дБ (в 10 раз по амплитуде) от пика.
Чистота тонаНасколько звук периодичен на найденной частоте, от 0 до 100%. Дребезг и посторонние призвуки её снижают.

▲ слабо ✓ норма ▼ туго ✕ брак

Брак — по описанию патента это глухой звук, быстрое затухание или негармонический дребезг:

  • «быстро затухает» — затухание короче 60% эталонного;
  • «дребезг, нечистый тон» — чистота тона ниже 75% эталонной или ниже 40%;
  • «глухой звук» — оба признака сразу.

Проверка на брак идёт раньше проверки частоты: изделие с браком отправляется на перетяжку, даже если частота в допуске.

Если вместо вердикта появилось «Тон не определился» — удар вышел глухим, шнур дребезжит или мешает шум. Ударьте ещё раз; если повторяется, изделие отправляется на дотяжку.

Пороги 60% и 75% установлены по умолчанию. В режиме «Про» их можно подобрать на своих изделиях или задать вручную — раздел 6. Вопросы и предложения: zaymozay@gmail.com.

5Журнал проверок

Каждый удар записывается: дата, время, частота, отклонение от эталона, затухание, чистота тона и вердикт. Последние восемь замеров видны на вкладке «Тюнер», итог по всем размерам — на вкладке «Холсты».

⬇ Выгрузить журнал (CSV) — таблица для Excel по всем размерам. На каждый размер хранится до 2000 последних замеров.

По журналу видно, сколько изделий проверено и сколько отправлено на дотяжку.

6Режим «Про»: проверка по регламенту

Для мастерских, где каждую проверку вносят в реестр: с номером заказа, исполнителем и контрольным ключом, с результатом и повторной проверкой после корректировки. Включается переключателем «Про» вверху экрана. Вкладки: «Проверка», «Реестр», «Эталоны».

Первая настройка

  1. ⚙ Параметры Про: организация (для печатных форм), исполнитель, контрольный ключ — идентификатор (например, К-01) и масса в граммах. Эти данные попадают в каждую запись.
  2. Вкладка «Эталоны» → + Перечень 20–120 см, шаг 10 см или + Своя длина. Длина — это сторона подрамника, на которой закреплён шнур.
  3. Для каждой длины запишите эталон на правильно натянутом изделии тем же ключом. Без эталона проверка этой длины недоступна. При перезаписи прежний эталон остаётся в истории.

Проверка изделия

  1. Введите номер заказа и выберите длину стороны со шнуром.
  2. Нажмите 🎙 Слушать удар и ударьте один раз по середине шнура. После удара приложение само перестаёт слушать.
  3. Осмотрите полотно и отметьте: «Провисания нет» или «Есть провисание».
  4. Нажмите ✓ Записать в реестр. Итог: соответствует — передать на упаковку или не соответствует — вернуть на корректировку с причиной.

Если в заказе несколько холстов одной длины, указывайте номер через дробь: 1234/1, 1234/2.

Повторная проверка

Изделия, возвращённые на корректировку, видны в списке «Ждут повторной проверки». После корректировки нажмите Проверить повторно: номер заказа и длина подставятся сами, в поле «Корректировка» укажите, что сделано. Повторная запись ссылается на первичную. Первичная запись о несоответствии не удаляется и не меняется.

Особые случаи

На экранеЧто делать
Нет отклика — тон не определилсяУдар был, а звука шнура нет: отметьте осмотр и запишите «не соответствует» с причиной «нет отклика». Если удара не было и микрофон поймал посторонний звук — «Удара не было — отменить».
Шумно или повторный удар во время затуханияЗатухание не измерено: запишите «проверка прервана» и проверьте ещё раз.
Выбрана не та длина или удар пришёлся не по середине шнураНажмите «Не засчитывать удар: записать „проверка прервана“» и проверьте заново. Пока результат удара не внесён, длину сменить нельзя, а при переходе на другие вкладки удар не пропадает.
Ключ заменёнПосле изменения идентификатора или массы ключа ударьте по изделию с эталонным натяжением. Отклик совпадает с эталоном — нажмите «Отклик сверен с эталонами». Не совпадает — перезапишите эталоны новым ключом.

Реестр, выгрузки и отчёт

На вкладке «Реестр» — счётчики, список ожидающих повторной проверки и последние записи. Записи не удаляются и не редактируются: ошибку исправляют новой проверкой.

  • ⬇ Реестр проверок (CSV) — все записи: номер, дата, заказ, длина, первичная или повторная, корректировка, частота, затухание, чистота тона, провисание, результат, причина, действие, итог изделия, исполнитель, ключ, эталон и пороги.
  • ⬇ Перечень эталонов (CSV) — действующие и заменённые эталоны по длинам, с ключом и именем аудиофайла. Сам аудиофайл сохраняется кнопкой ⬇ Аудиофайл на вкладке «Эталоны».
  • 🖨 Реестр РП-01 — печатная форма: паспорт ключа, перечень эталонов, все проверки, строка для подписи.
  • 🖨 Сформировать отчёт — отчёт ОТЧ-ПАТ-01 за выбранный период: итоги, причины несоответствия, разбивка по длинам, инструмент, эталоны, исполнители и вывод.

Печатные формы открываются в приложении; на телефоне в меню печати выберите «Сохранить как PDF».

Подбор порогов

«Эталоны» → Подбор порогов. Выберите длину, сделайте 10–15 ударов по заведомо годным изделиям и 5–10 — по нарочно недотянутым. Приложение предложит допуск по частоте и пороги брака, при которых годные проходят, и покажет, сколько недотянутых выявлено. Применить — пороги действуют для всех длин, допуск — для выбранной. Пороги, по которым шла проверка, сохраняются в каждой записи. Вручную пороги задаются в ⚙ Параметры Про.

Реестр хранится только на этом телефоне. Сохраняйте резервную копию хотя бы раз в неделю: «Реестр» → ⬇ Экспорт в файл. Если копия не сохранялась 7 дней, приложение напомнит.

7Резервная копия и перенос данных

Размеры, эталоны, журнал и реестр хранятся только на этом телефоне, без облака. Для переноса на другое устройство или в другую мастерскую нужен файл.

Всё сразу

⬇ Экспорт в файл и ⬆ Импорт из файла — внизу вкладки «Холсты», в режиме «Про» — на вкладке «Реестр». В файле всё: размеры, эталоны, журнал, параметры и реестр проверок. При импорте размеры, эталоны и настройки заменяются данными из файла, а записи реестра добавляются к имеющимся, без повторов.

Один эталон

На вкладке «Тюнер» для настроенного размера — ⬇ экспорт образца. На другом устройстве, в пустом слоте, — ⬆ Загрузить образец из файла. Так передаётся один эталон, остальные размеры не меняются.

8Если не работает микрофон

Чаще всего Android один раз запомнил отказ в доступе и больше не показывает запрос. Проверьте по порядку:

  1. Приложение из RuStore: Настройки телефона → Приложения → «Натяжка» → Разрешения → Микрофон → Разрешить.
  2. Версия в браузере: откройте ссылку в обычном Chrome, а не во встроенном окне другого приложения. Нажмите на значок слева от адреса → «Разрешения» → «Микрофон» → «Разрешить» и обновите страницу.
  3. Если пункта «Микрофон» нет — Настройки → Приложения → Chrome → Разрешения → Микрофон → Разрешить.
  4. На некоторых оболочках (например, ColorOS) есть отдельный «Диспетчер разрешений» в настройках приватности — проверьте и его.
Код ошибки вроде [NotReadableError] или [NotAllowedError] подскажет причину точнее общих шагов.
