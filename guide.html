1Быстрый старт

«TapTension» — инструмент для проверки натяжения гибкого подвеса (шнура) художественного полотна на подрамнике по звуку удара, по принципу гитарного тюнера.

  1. Откройте ссылку на приложение в браузере Chrome на телефоне.
  2. Нажмите значок ⚙ (на телефоне) или «Установить на телефон» и добавьте иконку на главный экран — приложение будет открываться как обычное, без адресной строки браузера.
  3. При первом использовании записи образца подтвердите системный запрос доступа к микрофону.
Важно: ссылку нужно открывать напрямую в Chrome, а не внутри другого приложения — иначе доступ к микрофону может быть недоступен.

2Эталон для размера холста

Каждый размер холста хранит свой эталонный звук — образец, с которым будут сравниваться дальнейшие проверки.

Добавление размера

На вкладке «Холсты» выберите готовый слот из сетки основных размеров или добавьте свой через «+ Свой размер».

Запись эталона

  1. Откройте нужный размер на вкладке «Тюнер».
  2. Нажмите «🎙 Записать образец» — приложение слушает 2,5 секунды.
  3. За это время стукните металлическим предметом (например, шестигранным ключом) по центру правильно натянутого шнура рядом с микрофоном.
  4. Прослушайте запись, при необходимости запишите заново, затем нажмите «Сохранить как эталон».
Используйте один и тот же предмет и точку удара каждый раз — от этого зависит, насколько корректно будут сравниваться показания.

Частоту эталона можно также ввести вручную в герцах, если она уже известна — без записи звука.

3Повседневная проверка

  1. Выберите размер холста в выпадающем списке на вкладке «Тюнер».
  2. Нажмите «🎙 Слушать и сравнивать».
  3. Стукните по центру шнура тем же предметом, что и при записи эталона.

Результат отображается сразу:

▲ слабое натяжение ✓ норма ▼ перетянуто

Точность измерения

  • Чувствительность (Тихо / Обычно / Шумно) — подбирается под уровень шума в помещении.
  • Усреднение — «Среднее по 3» использует последние три удара вместо одного, для более стабильного результата.
  • Телефон коротко вибрирует при каждом захвате звука и отдельно — если натяжение вне допуска.

4Резервная копия и перенос данных

Все размеры и эталоны хранятся локально на конкретном телефоне, без облака — поэтому для переноса между устройствами (или в другую типографию) нужен файл.

Весь список размеров

На вкладке «Холсты» внизу: ⬇ Экспорт в файл — сохраняет всё; ⬆ Импорт из файла — загружает обратно (с заменой текущих данных).

Один эталон

На вкладке «Тюнер», для настроенного размера: ⬇ экспорт образца. Для пустого слота на другом устройстве: ⬆ Загрузить образец из файла — так можно передать один конкретный эталон, не трогая остальные размеры.

5Если не работает микрофон

Самая частая причина — Android один раз запомнил отказ в доступе и больше не показывает запрос. Проверьте по порядку:

  1. Убедитесь, что ссылка открыта в обычном Chrome, а не во встроенном окне другого приложения.
  2. В Chrome нажмите на значок слева от адреса сайта → «Разрешения» → «Микрофон» → «Разрешить». Обновите страницу.
  3. Если пункта «Микрофон» там нет — проверьте системные настройки телефона: Настройки → Приложения → Chrome → Разрешения → Микрофон → Разрешить.
  4. На некоторых Android-оболочках (например, ColorOS) есть отдельный «Диспетчер разрешений» в настройках приватности — проверьте и там тоже.
Если приложение показывает точный код ошибки вроде [NotReadableError] или [NotAllowedError] — это подскажет причину точнее, чем общие шаги выше.
